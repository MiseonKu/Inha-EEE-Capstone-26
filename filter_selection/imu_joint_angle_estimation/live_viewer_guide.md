# 1호기 IMU 실시간 검증 화면 사용법

## 파일 구성

- `viewer_live.py`
  - 호스트 PC에서 실행하는 실시간 시각화 화면
- `demo.ino`
  - Arduino Uno 쪽 예제 스케치
  - 사람이 읽는 로그와 뷰어가 읽는 `VH/VD` CSV 스트림을 같이 출력함
- `Estimator.h`, `Estimator.cpp`
  - 자세 추정 및 관절각 추정 코어

## 화면에서 보이는 것

### 1. 좌측 3D 화면

- 기준 자세를 회색 점선으로 고정 표시
- 실시간 추정 자세를 파란색 링크로 표시
- 손끝 궤적을 붉은 선으로 표시
- 힌지축 방향을 점선 보조축으로 표시
- 예시 이미지보다 팔이 더 크게 보이도록 화면 비율과 축 범위를 더 타이트하게 잡아둠

### 2. 우측 파형/정보 영역

- 선택한 IMU 1개의 가속도 파형
- 선택한 IMU 1개의 자이로 파형
- 팔꿈치각 / 상완 기울기 / 전완 기울기 추정 파형
- 현재 IMU 값 3개(U1/U2/F1) 전부를 숫자로 같이 출력
- 상완 일치도, 전완 동적 패널티, confidence 값 표시

## 필요한 패키지

호스트 PC에 아래 패키지가 있어야 함

```bash
pip install numpy matplotlib pyserial
```

## 1. 화면만 먼저 확인하고 싶을 때

하드웨어 연결 없이 데모 모드로 먼저 볼 수 있음

```bash
python viewer_live.py --demo
```

이 모드는 합성 데이터를 만들어서

- 3D 로봇팔 움직임
- IMU 파형
- 추정 각도 파형

이 어떻게 보이는지 바로 확인하게 해줌

## 2. 실제 1호기와 연결해서 볼 때

### Arduino 쪽

1. `demo.ino`를 업로드
2. `readImuPoseSample()` 안에 기존 IMU 필터 출력 연결
3. 기준 자세 캘리브레이션 후 연속 추정 모드 시작

### PC 쪽

```bash
python viewer_live.py --port COM12
```

포트 번호는 실제 장치에 맞게 바꾸면 됨

필요하면 CSV도 같이 저장 가능

```bash
python viewer_live.py --port COM12 --csv live_capture.csv
```

종료 시 현재 화면 이미지를 저장하고 싶으면

```bash
python viewer_live.py --port COM12 --save-figure live_view.png
```

## 보드와 뷰어 사이의 데이터 형식

### 헤더

```text
VH,millis,mode,...
```

### 데이터

```text
VD,1234,3,1,...
```

- `VH`: 필드명 헤더
- `VD`: 실시간 데이터 한 줄
- `# `: 사람이 읽는 상태 메시지

즉 뷰어는 `VD` 줄만 읽고, `#` 로그는 상태창 메시지로만 사용함

## 키보드 단축키

뷰어 창을 선택한 상태에서 사용

- `1`
  - 상완 IMU 1 파형 표시
- `2`
  - 상완 IMU 2 파형 표시
- `3`
  - 전완 IMU 1 파형 표시
- `r`
  - 기준 90도 자세 캘리브레이션 시작
- `e`
  - 힌지축 보정 시작
- `g`
  - 연속 추정 시작
- `x`
  - 정지
- `p`
  - 보드에서 뷰어 헤더 다시 출력
- `v`
  - 뷰어용 CSV 스트림 on/off

## 권장 사용 순서

1. 먼저 `python viewer_live.py --demo` 로 화면 배치 확인
2. 실제 보드 연결
3. 기준 자세에서 `r`
4. 필요하면 팔꿈치 축 보정으로 `e`
5. 연속 추정 시작 `g`
6. 화면에서
   - 3D 자세 모양
   - IMU 파형
   - 팔꿈치각 / 기울기
   - consistency / penalty
   를 동시에 확인

## 실제 검증할 때 특히 볼 것

- 기준 자세로 돌아왔을 때 팔 모양이 다시 기준 자세와 겹치는지
- 상완 IMU 2개의 `upper_consistency_deg` 가 과도하게 커지지 않는지
- 빠르게 움직일 때 `forearm_dynamic_penalty_mps2` 가 커지는지
- 팔꿈치 주/보조 추정값이 서로 심하게 벌어지지 않는지
- 눈으로 본 실제 팔 모양과 3D 화면이 같은 방향으로 움직이는지

## 주의

- 지금 구조는 절대 yaw 복원기가 아니라 상완-전완 체인의 자세 검증 화면임
- 따라서 팔꿈치 굽힘과 링크 기울기 확인에는 강하지만, 전체 5자유도 절대 자세 복원 화면으로 보면 안 됨
- 필터가 업그레이드되면 `readImuPoseSample()` 연결부만 유지해도 이 화면은 계속 재사용 가능함
