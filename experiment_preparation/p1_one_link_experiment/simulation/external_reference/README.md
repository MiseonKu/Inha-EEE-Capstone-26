# External Reference Notes

The P1 simulation package was created as a clean local model from the explicit
AlphaF P1 geometry. The upstream SO-ARM100 repository was inspected for naming,
layout, mesh, and simulation conventions, but no upstream mesh or URDF file was
copied into this workspace.

See `source_info.json` and `simulation/docs/external_source_notes.md` for the
exact source URL, commit, license, and inspected files.
