# Validation Plan P2

After real data is collected, validate:

- expected rigid target cloud vs actual Vive settled cloud
- residual bias by x/y/z
- residual bias by azimuth/radial/height/posture bins
- coverage imbalance
- coordinate-frame mismatch
- scale mismatch
- session quality and tracker availability

The validation should report PASS, PASS_WITH_WARNING, FAIL, and NOT_TESTED status per check.
